## 1. 使いはじめる

### 1.1 ログインする

1. アプリを開きます。ログイン画面が表示されます
2. メールアドレスとパスワードを入力します
3. 「Sign in」を選びます
4. 「Dashboard」が表示されれば完了です

アカウントは管理者が作成します。ご自身で新規登録することはできません。

### 1.2 Anki とつながるようにする

はじめに 1 回だけ必要な設定です。**これを行わないとカードを Anki へ送れません。**

1. Anki Desktop を開き、**Tools → Add-ons → AnkiConnect → Config** を選びます
2. `webCorsOriginList` に、お使いのアプリのアドレス (例: `http://localhost:3000`) を追加します
3. Anki Desktop を再起動します
4. AnkiFlow の画面左下に接続状態が表示されます。緑色になれば成功です

うまくいかないときは FAQ の「Anki につながりません」をご覧ください。

### 1.3 学習する言語を選ぶ

1. 左のメニューから「Settings」を選びます
2. 学習したい言語を選びます。複数選べます
3. 説明を書く言語 (Output Language) も選べます。学習する言語とは別に設定できます
4. 「Save」を選びます

## 2. カードを作る

### 2.1 1 語ずつ作る

いちばん基本的な使い方です。

1. 左のメニューから「Create Card」を選びます
2. 種類 (語学 / IT 用語 / 一般知識) を選び、デッキやカテゴリを選びます
3. 覚えたい語を入力します
4. 生成のボタンを選びます。AI が意味・例文・発音を作り、画像と音声も用意します
5. 確認画面に切り替わります。次は 2.4 へ進みます

2 語目からは、デッキやカテゴリを選び直す必要はありません。前回の選択がそのまま残ります。

### 2.2 まとめて作る

複数の語を一度に作れます。

1. 「Create Card」で「Creation mode」を切り替えます
2. 覚えたい語を改行で区切って入力します
3. 生成のボタンを選びます
4. 一覧の確認画面に切り替わります。いらないカードはここで捨てられます
5. まとめて Anki へ送ります

### 2.3 内容を直してから送る

確認画面では、どの項目も直せます。

1. 直したい項目を選びます
2. 内容を書き換えます
3. カードの表と裏を切り替えて、見え方を確かめられます
4. 画像が気に入らないときは、選び直せます
5. 問題なければ 2.4 へ進みます

### 2.4 Anki へ送る

Anki が起動しているかどうかで選ぶボタンが変わります。

| 状況 | 選ぶもの | どうなるか |
| --- | --- | --- |
| Anki が起動している | 「Save & Export to Anki」 | すぐに Anki へ登録されます |
| Anki を開いていない | 「Save」 | いったん保存され、あとでまとめて送れます |

送り終えると入力欄が空になり、次の語をすぐに入力できます。

### 2.5 あとでまとめて Anki へ送る

2.4 で「Save」を選んだカードを、まとめて登録します。

1. Anki Desktop を起動します
2. AnkiFlow を開きます
3. 左のメニューの下にある同期のボタンを選びます
4. 「Synced ○ cards」と表示されれば完了です

### 2.6 同じ語をもう一度作ろうとしたとき

すでに作った語を入力すると、生成の前に警告が出ます。

1. 警告が表示されます
2. 作るのをやめる、そのまま作る、のどちらかを選べます
3. そのまま作った場合、Anki 側に同じ語のカードが 2 つできます

## 3. 作ったカードを扱う

### 3.1 過去に作ったカードを探す

1. 左のメニューから「History」を選びます
2. 種類・言語・状態・カテゴリで絞り込めます
3. 語を入力して検索することもできます
4. 見たいカードを選ぶと詳細が開きます

### 3.2 登録済みのカードを直す

1. 「History」から直したいカードを開きます
2. 内容を書き換えます
3. 保存します。Anki 側のカードにも反映されます

Anki が起動していない場合は反映できません。Anki を起動してからやり直してください。

### 3.3 カードを消す

1. 「History」で消したいカードを選びます
2. まとめて選ぶこともできます
3. 削除を選びます
4. Anki 側のカードも一緒に消えます

消したカードは元に戻せません。ご注意ください。

### 3.4 同じ条件でもう一度作る

内容を作り直したいときに使います。

1. 「History」からカードを開きます
2. 作り直しを選びます
3. 同じ条件が入った状態で「Create Card」が開きます
4. 必要なら内容を変えて、もう一度生成します

## 4. 自分に合わせて整える

### 4.1 デッキ・カテゴリ・カードタイプを増やす

1. 左のメニューから「Admin」を選びます
2. 増やしたいものの区分を選びます
3. 追加します
4. 名前などを入力して保存します

ここで作ったものは、次にカードを作るときから選べるようになります。

### 4.2 カードの見た目を変える

出題の向き (単語→意味、音声→単語 など) ごとに、表と裏に何を載せるかを変えられます。

1. 「Admin」からカードタイプを開きます
2. 表と裏に載せる項目を選びます
3. 保存します
4. 次に作るカードから反映されます

### 4.3 新しい種類の学習内容を追加する

語学・IT 用語・一般知識以外のものを扱いたいときに使います。

1. 「Admin」または「Settings」からコンテンツタイプの追加を選びます
2. 左側で名前と入力項目を決めます
3. 右側で AI に作らせたい項目とその指示を決めます
4. 右側の試用で、実際にどう生成されるか試せます
5. 保存します

作ったあとに識別用のコードは変えられません。最初に決めてください。

## 5. すきま時間に復習する

LINE で復習の通知を受け取れます。Anki を開かなくても、通知の上で内容を確認できます。

### 5.1 LINE とつなぐ

1. 「Settings」を開き、「LINE Notifications」の「Enable LINE reminders」を有効にします
2. 表示された連携コードを控えます
3. LINE で AnkiFlow の公式アカウントを友だちに追加します
4. そのトークにコードを送ります
5. 連携済みと表示されれば完了です

**コードの有効期限は 10 分です。** 過ぎた場合は、もう一度発行してください。

### 5.2 通知を止める

1. 「Settings」を開きます
2. 「Enable LINE reminders」を無効にします

連携そのものを解除したい場合は、「Unlink LINE account?」から行えます。

### 5.3 通知が届くしくみ

- 復習の時期が来た語を、システムが自動で選びます
- 配信する時刻は管理者が設定します。お住まいの地域の時刻で判定されます
- 通知が最大で 1 時間ほど遅れることがあります。これは仕様です

## 6. 管理者の方へ

本章はアプリの管理者のみが対象です。

### 6.1 費用のかかる機能を止める

AI・音声・画像は外部サービスを使うため費用がかかります。使いすぎたときは全体で止められます。

1. 「Settings」から「App Settings」を開きます
2. 止めたい機能を無効にします
3. すぐに全利用者へ反映されます

再起動や設定ファイルの変更は不要です。

### 6.2 新しく登録する人の初期データを変える

1. 「Admin」を開きます
2. 編集する対象を、新規利用者向けの初期データに切り替えます
3. デッキやカテゴリなどを編集します

**すでに登録済みの方には反映されません。** これから登録する方にのみ適用されます。

### 6.3 使う AI を変える

1. 「Settings」から「App Settings」を開きます
2. 使用する AI モデルを選びます
3. 保存します

## 7. 覚えておくと便利なこと

| こと | 内容 |
| --- | --- |
| 入力条件は残ります | デッキやカテゴリは、次の語を作るときもそのままです |
| Anki なしでも作れます | 生成・確認・保存までは Anki を開かずに行えます |
| 学習は Anki で行います | AnkiFlow に復習の画面はありません |
| 他の端末で学ぶには | Anki Desktop と AnkiWeb を同期してください |
| 音声や画像がなくても作れます | 用意できなかった場合も、カードは作成できます |
| Safari は使えません | Anki と連携する場合は Chrome・Edge・Firefox をお使いください |

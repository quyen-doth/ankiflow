## 1. Anki につながらない

### 1.1 「Anki につながりません」と出ます

**この表示が出る原因は 3 つあり、アプリからは見分けられません。** ブラウザが詳しい理由を教えてくれないためです。そのため、上から順にお試しください。

| # | 確認すること |
| --- | --- |
| 1 | Anki Desktop が起動していますか |
| 2 | AnkiConnect アドオンが入っていますか |
| 3 | `webCorsOriginList` にこのアプリのアドレスを入れましたか (1.2 を参照) |
| 4 | 設定後、Anki を再起動しましたか |
| 5 | Safari をお使いではありませんか (1.4 を参照) |
| 6 | 公開されているアドレスからお使いではありませんか (1.3 を参照) |

### 1.2 CORS の設定はどうすればよいですか

1. Anki Desktop で **Tools → Add-ons → AnkiConnect → Config** を開きます
2. 次のように、お使いのアドレスを加えます

    ```json
    {
        "webCorsOriginList": ["http://localhost", "http://localhost:3000"]
    }
    ```

3. Anki Desktop を**再起動します**。再起動しないと反映されません

### 1.3 設定したのに、公開版からだけつながりません

ブラウザ側の制限によるものです。**アプリを直すことでは解決できません。**

最近のブラウザには、インターネット上のページから、お使いのパソコンの中 (`localhost`) へ通信することを止めるしくみがあります。`webCorsOriginList` を正しく設定しても届きません。

対処は次のいずれかです。

| # | 対処 |
| --- | --- |
| 1 | 接続を許可するか尋ねられたら、許可します |
| 2 | Anki へ送るときだけ、`http://localhost:3000` からアプリを開きます |

### 1.4 Safari で使えますか

**Anki との連携には使えません。** Safari は、インターネット上のページから `localhost` への接続を認めていないためです。

Chrome・Edge・Firefox のいずれかをお使いください。

なお、カードを作って保存するところまでは Safari でも行えます。Anki への登録だけができません。

### 1.5 Anki を開かずに使えますか

**使えます。** 作成・確認・保存までは Anki なしで行えます。

保存したカードは、あとで Anki を起動してから、左のメニューの同期ボタンでまとめて登録できます。

## 2. カードの作成でつまずく

### 2.1 「すでに登録されています」と出ます

同じ語をすでに作っているという警告です。

そのまま作ることもできます。その場合、Anki 側に同じ語のカードが 2 つできます。

### 2.2 生成が失敗します

| 確認すること | 対処 |
| --- | --- |
| 通信は安定していますか | つなぎ直してからやり直します |
| 管理者が AI を止めていませんか | 管理者にお問い合わせください |
| 何度やっても失敗しますか | 少し時間をおいてからお試しください |

入力した内容は失われません。やり直せます。

### 2.3 生成された内容が正しくありません

AI が作るため、誤りが含まれることがあります。

確認画面ですべての項目を直せます。**Anki へ送る前に必ずご確認ください。**

### 2.4 選びたいカードタイプが出てきません

カードタイプには、対象とする学習言語と説明の言語が設定されています。**両方が一致するものだけが表示されます。**

「Admin」からカードタイプの設定をご確認ください。どちらも指定していないカードタイプは、常に表示されます。

### 2.5 入力欄が思っていたものと違います

入力欄は、選んだ種類 (コンテンツタイプ) の設定から作られます。

変えたい場合は「Admin」からその種類を開き、入力項目を編集してください。

### 2.6 前に選んだデッキが残っていません

種類 (コンテンツタイプ) ごとに別々に記憶されます。種類を切り替えると、その種類で前回選んだ内容に変わります。

また、項目によっては毎回まっさらに戻る設定になっています。

## 3. 音声・画像が出ない

### 3.1 音声が作られません

| 確認すること | 対処 |
| --- | --- |
| 管理者が音声機能を止めていませんか | 管理者にお問い合わせください |
| 対応していない言語ではありませんか | 言語によっては音声を用意できません |

音声がなくてもカードは作れます。

### 3.2 例文の音声が出ません

**選んでいるカードタイプが例文の音声を使う場合にのみ作られます。**

使わないカードタイプを選んでいるときに作らないのは、余計な費用をかけないためです。例文の音声が必要な場合は、それを使うカードタイプを選んでください。

### 3.3 画像が見つかりません

適切な画像が見つからないことがあります。別の語で探し直すか、画像なしで作成してください。

### 3.4 Anki で音声が鳴りません、画像が出ません

| 確認すること | 対処 |
| --- | --- |
| Anki へ送るときにエラーが出ませんでしたか | もう一度送り直します |
| AnkiWeb と同期しましたか | 別の端末で見る場合は同期が必要です |

## 4. LINE 通知が届かない

### 4.1 連携できません

| 確認すること | 対処 |
| --- | --- |
| コードの有効期限が切れていませんか | **10 分で切れます。** 発行し直してください |
| 公式アカウントを友だちに追加しましたか | 追加してから送ってください |
| コードを正しく送りましたか | 余分な文字が入っていないかご確認ください |

### 4.2 連携したのに通知が来ません

| 確認すること | 対処 |
| --- | --- |
| 「Enable LINE reminders」は有効ですか | 「Settings」でご確認ください |
| 復習の時期が来たカードはありますか | 対象がない場合、通知は送られません |
| Anki へ登録済みのカードはありますか | 保存しただけのカードは対象になりません |
| 配信時刻を過ぎていますか | 時刻は管理者が設定します |

### 4.3 通知の時間がずれます

**最大で 1 時間ほど遅れることがあります。** これは仕様です。

配信のしくみが動かなかった時間帯を、次の回で補うようにしているためです。同じ内容が二重に届くことはありません。

### 4.4 通知を止めたいです

「Settings」で「Enable LINE reminders」を無効にしてください。

連携そのものを解除する場合は「Unlink LINE account?」から行えます。

## 5. 表示・動作について

### 5.1 画面が英語です。日本語にできますか

**できません。** 画面の表示は英語のみです。

### 5.2 一覧に何も表示されません

| 確認すること | 対処 |
| --- | --- |
| 絞り込みが残っていませんか | 条件を外してご確認ください |
| ログインし直すと直りますか | 一度ログアウトしてお試しください |
| それでも直りませんか | 管理者にお問い合わせください |

### 5.3 スマートフォンで使えますか

**カードの作成には向きません。** パソコンでの利用を想定した画面です。

復習は Anki のスマートフォン版で行えます。LINE の通知もスマートフォンで受け取れます。

### 5.4 自分でアカウントを作れますか

**できません。** 現在、一般の方の登録は受け付けていません。管理者がアカウントを作成します。

## 6. 仕様に関する質問

### 6.1 AnkiFlow で復習はできますか

**できません。** AnkiFlow はカードを作るためのものです。

復習は Anki で行います。間隔をあけて出題するしくみは、実績のある Anki に任せる方針です。

### 6.2 他の端末で学習するには

Anki Desktop と AnkiWeb を同期してください。同期後、スマートフォンやタブレットの Anki で学習できます。

AnkiFlow が直接ほかの端末へ送ることはありません。

### 6.3 作ったカードは AnkiFlow がないと使えなくなりますか

**そのようなことはありません。** カードは Anki 側にも保存されます。AnkiFlow を使わなくなっても、Anki でそのまま学習を続けられます。

### 6.4 ほかの人のカードは見られますか

**見られません。** 利用者ごとにデータは完全に分かれています。共有する機能はありません。

### 6.5 費用はかかりますか

利用者に費用はかかりません。外部サービスの費用は管理者が負担します。

そのため、使いすぎた場合には管理者が機能を止めることがあります。

### 6.6 一度に何語まで作れますか

上限は設けていませんが、一度に多く作るとその分だけ時間がかかります。

### 6.7 消したカードは元に戻せますか

**戻せません。** 削除すると Anki 側のカードも一緒に消えます。

### 6.8 コンテンツタイプのコードを変えたいです

**作成後は変えられません。** どの入力画面を出すかを決める大切な値のためです。

変えたい場合は、新しく作り直してください。

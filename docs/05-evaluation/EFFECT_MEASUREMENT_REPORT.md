## 11. 学習効果について

**本測定は学習効果を測定していない。** 事前事後のテスト、十分な期間、対照群、交絡要因の統制のいずれも備えていないためである。

> 作成の負担が下がる → 作成を継続できる → 触れる語彙数が増える → 定着の機会が増える
